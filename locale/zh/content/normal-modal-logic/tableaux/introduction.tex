\olsection{引言}

!!^{tableau}是（向下分支的）!!{signed
  formula}树，即由真值符号（$\True$ 或
$\False$）与!!a{sentence}组成的对
\[
\sFmla{\True}{!A} \text{ 或 } \sFmla{\False}{!A}.
\]
!!^a{tableau}从若干\emph{假设}开始。每一个进一步的!!{signed formula}由应用某条推理规则产生。某些推理规则向树的
尖端添加一个或多个!!{signed formula}；另一些规则添加两个新尖端，从而产生两个
支。规则产生的!!{signed formula}中的!!{formula}比所应用到的那个!!{signed formula}中的公式更简单。当一个支既包含
$\sFmla{\True}{!A}$ 又包含 $\sFmla{\False}{!A}$ 时，我们说该支是
\emph{闭的}。如果!!a{tableau}中的每一个支都是闭的，整个!!{tableau}就是闭的。一个
闭的!!{tableau}构成!!a{derivation}，表明用来开始该!!{tableau}的!!{signed formula}的那个集合是不可满足的。这可以用来定义
$\Proves$ 关系：$\Gamma \Proves !A$ 当且仅当存在某个有穷集
$\Gamma_0 = \{!B_1, \dots, !B_n\} \subseteq \Gamma$，使得对下列假设存在一个
闭的!!{tableau}
\[
\{\sFmla{\False}{!A}, \sFmla{\True}{!B_1}, \dots, \sFmla{\True}{!B_n}\}.
\]

对于模态逻辑，我们既要扩展!!{signed
  formula}的概念，又要添加规则来
覆盖~\iftag{prvBox}{$\Box$\iftag{prvDiamond}{ 和
    $\Diamond$}}{$\Diamond$}。除符号（$\True$ 或
$\False$）之外，模态!!{tableau}中的!!{formula}还带有
\emph{前缀}~$\sigma$。前缀是非空的正整数序列，
即 $\sigma \in (\PosInt)^* \setminus
\{\emptyseq\}$。当我们书写这样的前缀而略去周围的
$\tuple{\ }$，并用~$.$ 而不是 $,$ 来分隔各个!!{element}时，
如果 $\sigma$ 是前缀，则 $\sigma.n$ 是 $\sigma
\concat \tuple{n}$；例如，若 $\sigma = 1.2.1$，则 $\sigma.3$ 是
$1.2.1.3$。因此例如，
\[
\sFmla{\True}{\Box !A \lif !A}[1.2]
\]
是\emph{带前缀的!!{signed formula}}（或简称为\emph{带前缀的!!{formula}}）。

直观地看，前缀为!!a{tableau}某支上的!!{formula}指明模型中的一个世界，这个世界可能满足这些公式，而若 $\sigma$ 指定某个世界，则 $\sigma.n$ 指定一个（由~$\sigma$ 所指定的世界）可及的世界。

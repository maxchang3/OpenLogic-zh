\olsection{二阶可定义性}

并非每个由模态公式可定义的框架性质都是一阶可定义的。然而，如果我们允许对一元谓词进行量化（即一元二阶量化），那么我们就能定义一切模态可定义的框架性质。窍门在于利用一种系统的方式，把「一个模态!!{formula}在世界处为真的那些条件」与一阶!!{formula}相互关联。这就是所谓把模态公式标准翻译为一阶公式，所用语言不仅包含用于可及关系的二元!!{predicate}~$Q$，还包含用于出现在~$!A$ 中的!!{propositional variable}~$\Obj p_i$ 的一元!!{predicate}~$P_i$。

\begin{defn}
  \emph{标准翻译}~$\ST_x(!A)$ 按如下方式归纳定义：
  \begin{enumerate}
  \tagitem{prvFalse}{\indcase{!A}{\lfalse}{$\ST_x(\indfrm) = \lfalse$.}}{}
  \tagitem{prvTrue}{\indcase{!A}{\lfalse}{$\ST_x(\indfrm) = \ltrue$.}}{}
  \item \indcase{!A}{\Obj p_i}{$\ST_x(\indfrm) = \Atom{P_i}{x}$.}
  \tagitem{prvNot}{\indcase{!A}{\lnot !B}{$\ST_x(\indfrm) = \lnot \ST_x(!B)$.}}{}
  \tagitem{prvAnd}{\indcase{!A}{(!B \land !C)}{$\ST_x(\indfrm) = (\ST_x(!B)
      \land \ST_x(!C))$.}}{}
  \tagitem{prvOr}{\indcase{!A}{(!B \lor !C)}{$\ST_x(\indfrm) = (\ST_x(!B)
      \lor \ST_x(!C))$.}}{}
  \tagitem{prvIf}{\indcase{!A}{(!B \lif !C)}{$\ST_x(\indfrm) = (\ST_x(!B)
      \lif \ST_x(!C))$.}}{}
  \tagitem{prvIff}{\indcase{!A}{(!B \liff !C)}{$\ST_x(\indfrm) = (\ST_x(!B)
      \liff \ST_x(!C))}$.}{}
  \tagitem{prvBox}{\indcase{!A}{\Box !B}{$\ST_x(\indfrm) =
      \lforall[y][(\Atom{Q}{x,y} \lif \ST_y(!B))]$.}}{}
  \tagitem{prvDiamond}{\indcase{!A}{\Diamond !B}{$\ST_x(\indfrm) =
      \lexists[y][(\Atom{Q}{x,y} \land \ST_y(!B))]$.}}{}
  \end{enumerate}
\end{defn}

例如，$\ST_x(\Box p \lif p)$ 就是 $\lforall[y][(\Atom{Q}{x,y}
  \lif \Atom{P}{y})] \lif \Atom{P}{x}$。任何用于~$\ST_x(!A)$ 之语言的!!{structure}都要求一个论域、一个指派给~$Q$ 的二元关系，以及指派给一元!!{predicate}~$P_i$ 的论域子集。换句话说，这样的!!a{structure}的诸成分恰是 ~$!A$ 的一个模型的各组成成分：论域是世界之集合，指派给~$Q$ 的二元关系就是可及关系，指派给~$P_i$ 的子集就是赋值~$V(\Obj p_i)$。模态模型中 $!A$ 的可满足性与相应!!{structure}中 $\ST_x(!A)$ 的可满足性一致，这一点不令人意外：

\begin{prop}\ollabel{prop:st}
  设 $\mModel{M} = \tuple{W, R, V}$，$\Struct{M'}$ 是以 $\Domain{M'} = W$、$\Assign{Q}{M'} = R$、$\Assign{P_i}{M'} = V(\Obj p_i)$ 的一阶!!{structure}，且 $s(x) = w$。则
  \[
  \mSat{M}{!A}[w] \text{ 当且仅当 } \Sat{M'}{\ST_x(!A)}[s]
  \]
\end{prop}

\begin{proof}
  对~$!A$ 进行归纳。
\end{proof}

\begin{prop}
  设 $!A$ 是一个模态!!{formula}，$\mModel{F} = \tuple{W, R}$ 是一个框架。令 $\Struct{F'}$ 是以 $\Domain{F'} = W$、$\Assign{Q}{F'} = R$ 的一阶!!{structure}，并令 $!A'$ 是如下二阶公式
  \[
  \lforall[X_1][\dots\lforall[X_n][\lforall[x][
        \SSubst{\ST_x(!A)}{\subst{X_1}{P_1}, \dots,
          \subst{X_n}{P_n}}]]],
  \]
  其中 $P_1$, \dots, $P_n$ 是~$\ST_x(!A)$ 中所有的一元!!{predicate}。则
  \[
  \mModel{F} \Entails !A \text{ 当且仅当 } \Sat{F'}{!A'}
  \]
\end{prop}

\begin{proof}
  $\Sat{F'}{!A'}$ 当且仅当对每个 $i = 1$, \dots,~$n$ 均满足 $\Assign{P_i}{M'} \subseteq W$ 的!!{structure}~$\mModel{M'}$，以及对每个满足 $s(x) \in W$ 的 $s$，都有 $\Sat{M'}{\ST_x(!A)}[s]$。根据 \olref{prop:st}，这当且仅当对所有基于~$\mModel{F}$ 的模型~$\mModel{M}$ 和每个世界~$w \in W$，都有 $\mSat{M}{!A}[w]$，即 $\mModel{F} \Entails !A$。
\end{proof}

\begin{defn}
  一个框架类~$\mClass{F}$ 是\emph{二阶可定义的}，如果存在二阶语言中的某个!!a{sentence}~$!A$，其只有一个二元!!{predicate}~$P$，且量化仅覆盖一元集合变元，使得 $\mModel{F} = \tuple{W, R} \in \mClass{F}$ 当且仅当在 $\Domain{M} = W$、$\Assign{P}{M} = R$ 的!!{structure}~$\Struct{M}$ 中有 $\Sat{M}{!A}$。
\end{defn}

\begin{cor}
  如果一个框架类由某个!!a{formula}~$!A$ 可定义，那么相应的可及关系类由一个一元二阶语句可定义。
\end{cor}

\begin{proof}
  前一证明中的一元二阶语句~$!A'$ 具有所要求的性质。
\end{proof}

作为例子，再次考虑!!{formula}~$\Box p \lif p$。它定义自反性。自反性当然可由!!{sentence}~$\lforall[x][\Atom{Q}{x,x}]$ 一阶可定义。但它也可由下面的一元二阶!!{sentence}定义：
\[
\lforall[X][\lforall[x][(\lforall[y][(\Atom{Q}{x,y} \lif \Atom{X}{y})]
    \lif \Atom{X}{x})]].
\]
这当然意味着这两个语句等价。以下是你可以直接说服自己的方法：首先设这个二阶语句在!!a{structure}~$\Struct{M}$ 中为真。由于 $x$ 和 $X$ 是全称量化的，余下的部分必须对任何 $x \in W$ 和集合~$X \subseteq W$ 都成立，例如集合 $\Setabs{z}{Rxz}$，其中 $R = \Assign{Q}{M}$。于是，对任何满足 $s(x) \in W$ 且 $s(X) = \Setabs{z}{Rxz}$ 的~$s$，我们有 $\Sat{M}{\lforall[y][(\Atom{Q}{x,y} \lif
    \Atom{X}{y})] \lif \Atom{X}{x}}$。但根据我们选取 $s(X)$ 的方式，那意味着 $\Sat{M}{\lforall[y][(\Atom{Q}{x,y} \lif
    \Atom{Q}{x,y})] \lif \Atom{Q}{x,x}}[s]$，由于前件是有效的，这等价于 $\Atom{Q}{x,x}$。由于 $s(x)$ 是任意的，我们有 $\Sat{M}{\lforall[x][\Atom{Q}{x,x}]}$。

现在设 $\Sat{M}{\lforall[x][\Atom{Q}{x,x}]}$ 并证明 $\Sat{M}{\lforall[X][\lforall[x][(\lforall[y][(\Atom{Q}{x,y} \lif
        \Atom{X}{y})] \lif \Atom{X}{x})]]}$。任取一个赋值~$s$，并假设 $\Sat{M}{\lforall[y][(\Atom{Q}{x,y} \lif
    \Atom{X}{y})]}[s]$。令 $s'$ 是~$s$ 的满足 $s'(y) = s(x)$ 的 $y$-变体；我们有 $\Sat{M}{\Atom{Q}{x,y} \lif \Atom{X}{y}}[s']$，即 $\Sat{M}{\Atom{Q}{x,x} \lif \Atom{X}{x}}[s]$。由于 $\Sat{M}{\lforall[x][\Atom{Q}{x,x}]}$，前件为真，于是 $\Sat{M}{\Atom{X}{x}}[s]$，这正是我们需要证明的。

由于某些可定义的框架类不是一阶可定义的，并非每种形如~$!A'$ 的一元二阶!!{sentence}都等价于一个一阶!!{sentence}。没有有效的方法能判定其中哪些等价于一个一阶语句。

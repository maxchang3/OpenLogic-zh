# OpenLogic-Zh 共同翻译政策

本文件记录所有翻译模块共同遵守的不变量与已经确认的风格决定；具体英文—中文对照见 `terminology/terms.json`。

## 源文件与译文边界

- `content/` 是上游英文正文，默认不改动；译文写入 `locale/zh/content/`，保持相同相对路径。
- 保持 OpenLogicProject 的文件结构、标签和宏接口，优先采用可回馈上游的最小改动；不要把下游 B&D 的书名、封面或发行信息写进本仓库的正文规范。
- 文件头注释、`\documentclass` 块、`\begin{document}` 和 `\end{document}` 原样保留；文件路径、标签名、交叉引用参数和代码命令不翻译。

## TeX 与内容不变量

1. 只翻译散文；`\ollabel`、`\olref`、`\olimport`、`\olsection`、`\olfileid`、`\tagitem`、`\indcase`、`\iftag` 等宏及其标签参数原样保留。
   - 章节标题（`\olsection`/`\olchapter` 参数）中的宏同样必须保留：`\Log{K}`、`\Ax{K}` 等系统名宏不得简化为裸文本 `K`；`\usetoken{P}{...}`、`\usetoken{S}{...}` 不得改写成普通文字或 `!!{token}`（首次括注与书签机制依赖原形式）。
   - `\iftag` 的条件分支必须完整保留（含 FOL/PL 等多分支），不得把任一分支写死成固定内容；译文分支内的文字照常翻译。
2. 数学 `$...$`、`$$...$$`、`\[...\]` 和数学环境中的结构逐字符保留，不能把数学宏移到文本模式；数学中的 `\text{...}` 若表达普通文字可以翻译，但数学结构和变量不动。数学中的变量字母必须逐字符照录（曾有把 `u \in V(p)` 误写成 `w \in V(p)` 改变数学定义的案例），也不能把数学变量移出 `$...$`（如 `$p$-容纳球面` 写成 `p-容纳球面`）。
3. `!!{token}`、`!!a{token}`、`!!^a{token}` 等令牌及其英文键原样保留；译者不手工添加括号原文、冠词或复数，显示由 locale 术语表负责。翻译时不得把令牌替换成普通中文词（如把 `!!{formula}` 译成"公式"）——位置、键名与冠词变体（空/`a`/`^`/`^a`）必须与英文原文一一对应；英文令牌可能跨行书写（如 `!!{signed` 换行 ` formula}`），识别时先折叠空白。每批完成后运行 `python3 scripts/check-tokens.py` 机械校验（`OpenLogic-Zh/` 根下）。
4. `\olfileid{...}{...}{...}` 在译文文件中写为 `\olfileid[zh]{...}{...}{...}`，不可使用花括号代替方括号。
5. 章节、节和习题标题照译；英语语言形式本身（构式名称、语法例句和被讨论的英文句子）保留英文，作为内容的例句照常翻译。
6. 每个正文段落保持一行，不手动折行；列表一项一行，表格和代码块按 Markdown/TeX 语法书写。

## 语言与标点

- 人名、逻辑系统名和引用中的作者—年份保留原文；Open Logic Project 与 Open Logic Text 的写法按 `terms.json` 处理。
- 裸英文逻辑术语必须按相应术语包翻译；未覆盖的术语先查证通行译法，登记为暂定并报告，不在多个 worker 中各自发明译法。
- 正文英文逗号、句号、分号等改用中文标点；数学内容、宏参数、标签和代码中的 ASCII 标点保持原样。
- 英文引号对译为「」，嵌套引号用『』；不要在术语后手工补括号原文。
- `operator` 与 `connective` 分别译为「算子」与「联结词」；同一英文在不同语境需要不同译法时，必须在术语条目中写明语境，不能依靠隐式覆盖。

## 未决术语流程

未覆盖的逻辑或哲学术语先查找学界通行译法，交付报告中登记英文、候选中文、语境和来源；协调者把仍未确认的项目写入 `pending.md`。用户确认后将定译移入 `terminology/terms.json`，并同步 `locale/zh/open-logic-config.sty`（如它是令牌），再从 pending 删除。

## 已确认的跨模块决定

- `sound/soundness` →「可靠的/可靠性」；`complete/completeness` →「完全的/完全性」；`well-formed formula` →「合式公式」；`sequent calculus` →「矢列演算」。
- `uniform substitution` →「统一代入」；`syntactic`（逻辑学语境）→「句法的」，自然语言或程序语言的 `grammar` 才译为「语法」。
- `iff` →「当且仅当」；`i.e.` →「即」；`e.g.` →「例如」；`viz.` →「亦即」。
- 散文叙述采用无主句风格：`we show / we prove / we define` 等不逐字译出主语，按「证明。」「下证……」「往证……」处理（文学锋《模态逻辑导论》通篇此风格）；句法自然度优先，不强求机械一致。
